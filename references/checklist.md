# 交付前自检清单

按顺序执行。每一项都要有明确结论：通过，或修好后重新检查。不要把“应该没问题”当成通过。

## A. 文件与目录

- [ ] 输出文件名是 `index.html`，没有依赖其他本地文件。
- [ ] 文件编码为 UTF-8，首行是 `<!doctype html>`。
- [ ] 页面 `<title>` 与 `aria-label` 有实际内容，不是占位文字。
- [ ] 文件大小 ≤ 200KB（推荐 ≤ 80KB）。
- [ ] 代码注释使用中文，没有占位标记和未完成的旧代码，没有无用的调试输出。
- [ ] 若交付的是完整 Skill 仓库，`SKILL.md`、`README.md`、`LICENSE`、`.gitignore`、`examples/`、`references/` 齐全。

## B. 离线与单文件

- [ ] 关闭网络或开启浏览器离线模式，刷新页面，画面与交互正常。
- [ ] 开发者工具 Network 面板中，除 `index.html` 本身外没有其他请求。
- [ ] 页面中没有 `<script src>`、`<link rel="stylesheet">`、`@import`、`url(http...)`。
- [ ] 页面中没有 `fetch(`、`XMLHttpRequest`、动态 `import()`。
- [ ] 没有使用 CDN、在线字体、外链图片、外链音频。
- [ ] 直接双击文件（`file://`）打开正常，不是只能通过本地服务器打开。
- [ ] 没有因为 `file://` 的 CORS 限制导致脚本失效。

快速静态检查：

```bash
grep -nE 'https?://|<script[^>]+src=|<link[^>]+href=|@import|fetch\(' index.html
grep -n 'Math\.random' index.html
```

两条命令都应该没有任何输出。

## C. 打开与首屏

- [ ] Chrome 或 Edge 最新版可正常打开。
- [ ] Firefox 最新版可正常打开。
- [ ] Safari（macOS/iOS）可正常打开。
- [ ] 首屏 1.5 秒内出现可辨认主体，不是长时间黑屏。
- [ ] 双击后自动播放，不需要点击。
- [ ] 页面没有横向滚动条。
- [ ] 桌面窗口拉高、拉宽时不裁切主体，舞台保持 9:16。
- [ ] 手机竖屏 360×640 视口下完整显示，不被地址栏遮住关键内容。
- [ ] 手机横屏时画面不拉伸变形，最多出现上下留黑。

## D. 动画质量

- [ ] 主体有明确的循环动作，不是静态图。
- [ ] 背景至少一个缓慢运动（粒子、扫描带、云、星空、网格）。
- [ ] HUD 至少一个变化（数值、闪烁、进度条）。
- [ ] 主体、背景、HUD 的运动周期不同，没有整屏同频。
- [ ] 动画在 10 秒后仍然成立，不会所有元素同时停住。
- [ ] 刷新 3 次，同一时间点的构图、粒子位置一致。
- [ ] 没有使用 `Math.random()`、`Date.now()`、当前时间参与图形生成。
- [ ] 页面切到后台 30 秒再切回，画面不跳变、不报错、不累积异常状态。
- [ ] 点击重播/暂停/继续的行为符合按钮提示。
- [ ] 快速缩放窗口不会出现 `NaN`、坐标溢出或白屏。

## E. 视觉质量

- [ ] 缩小到 320px 宽，仍能看出主体是什么。
- [ ] 主体高度约占画面 40%–65%，不是角落装饰。
- [ ] 背景与主体有明度差，主体轮廓有深色描边或亮部边缘光。
- [ ] 主色不超过 16 种，亮色面积不超过 15%。
- [ ] 扫描线没有把关键文字切断。
- [ ] 暗角没有压死主体，四角仍能看出场景。
- [ ] RGB 色差与故障效果不会导致文字重影难读。
- [ ] 画面内文字在手机上可读，关键 HUD 高度 ≥ 10 逻辑像素。
- [ ] 没有大面积模糊、柔和渐变，整体保持硬边像素感。
- [ ] 中文标题/说明与画面内英文 HUD 风格一致，不互相打架。

## F. 控制台与错误

- [ ] 控制台 0 个 error。
- [ ] 自己代码产生的 warning 为 0。
- [ ] 没有 404、CORS、跨域字体或图片来源报错。
- [ ] 没有 `undefined`、`null`、`NaN` 被绘制到画面上。
- [ ] 重播 10 次、切换标签页 3 次、缩放 5 次，控制台仍无报错。
- [ ] 移动端点击后没有触发页面缩放、选中文本或滚动。

## G. 性能与无障碍

- [ ] 桌面端动画流畅，没有明显掉帧。
- [ ] 中端手机打开后机身不过热，滚动页面不卡顿。
- [ ] 主循环中没有每帧新建大量对象、渐变或 DOM 节点。
- [ ] Canvas 有描述性 `aria-label`。
- [ ] 若使用按钮，键盘 Enter/Space 可用，`:focus-visible` 可见。
- [ ] 尊重 `prefers-reduced-motion`：降低闪烁和故障频率，保留主体运动。
- [ ] 页面没有超过 3Hz 的高频闪烁，没有全屏白闪。
- [ ] 文本对比度足够，重要信息不依赖颜色单独传达。

## H. 代码卫生

- [ ] 常量和调色板集中放在文件顶部。
- [ ] 绘制函数按背景、主体、HUD、CRT 拆分，命名能看出用途。
- [ ] 时间统一使用秒，变量名明确（`t`、`now`、`startTime`）。
- [ ] 所有 `requestAnimationFrame` 只有一个主循环。
- [ ] 没有未被调用的函数和大段注释掉的旧代码。
- [ ] 没有 `console.log` 留在最终文件里（调试用的 `console.warn` 也删除）。
- [ ] 浏览器兼容写法没有使用未定义前缀或实验 API。
- [ ] 代码中说明“为什么不用随机数”“为什么低分辨率”，而不是复述代码。

## I. 交付说明

- [ ] README 写清：这是什么、安装方式、触发方式、示例、目录结构、许可。
- [ ] README 中的命令可直接复制执行，路径与实际目录一致。
- [ ] 给出双击后的预期画面描述，不夸大效果。
- [ ] 说明如何换主题：改哪些常量、哪些绘制函数、哪些 HUD 文案。
- [ ] `LICENSE` 年份与版权人明确。
- [ ] `.gitignore` 不忽略最终产物（不要误把 `index.html` 或 `examples/` 忽略）。
- [ ] 提交前用 `git status` 确认只包含预期文件（这一步由用户自行执行）。

## 最终判定

以下任一情况出现，就不能称为“完成”：

- 需要联网或安装依赖才能看。
- 打开后黑屏超过 1.5 秒。
- 控制台有报错。
- 手机上看不清主体或文字。
- 画面不运动，或运动只在鼠标悬停时发生。
- 刷新后构图不同，无法复现。
- 只有抽象色块，用户看不出主题。

全部通过后，在交付信息中写一句：

```text
已按 references/checklist.md 完成自检：离线、单文件、无控制台报错、移动端可用、动画确定性通过。
```
